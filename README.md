## Features

- Single file: everything (HTML, CSS) lives in `index.html`.
- Responsive layout that works on phones, tablets and desktops.
- Automatic light and dark mode based on the system setting.
- Keyboard-friendly navigation with visible focus states.
- Respects the "reduce motion" accessibility setting.

## Tech

- HTML5 and CSS3 (custom properties for theming)
- Google Fonts (Bricolage Grotesque), with system font fallbacks

## Project structure

```
.
├── index.html   # the whole portfolio
└── README.md
```

If your copy of the page is named `portfolio.html`, rename it to `index.html` so hosting services pick it up automatically.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in any modern browser.

No server, installation or build command is needed.

## Customize

- **Content:** edit the text inside `index.html`, section by section (`about`, `skills`, `experience`, `projects`, `education`, `contact`).
- **Colors:** change the variables at the top of the `<style>` block (`--accent`, `--amber`, `--bg`, `--ink`). Dark mode values are in the second set of variables.
- **Project links:** add a link to each project's GitHub repository inside its `<article class="proj">` block.

## Deploy with GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and the `/ (root)` folder.
4. Save. The site will be live at `https://<your-username>.github.io/<repository-name>/` after a minute or two.

Netlify and Vercel also work: drag the folder in or connect the repository, and leave the build command empty.
